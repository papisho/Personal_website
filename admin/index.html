Opens Pages CMS, your content editor, in a new tab.

First time here?

  1. Sign in with GitHub using your papisho account.
  2. Authorize Pages CMS. When GitHub asks which repositories it can access, select only Personal_website.
  3. Open Personal_website → main. The editing forms are already configured.
  4. Edit and save. GitHub Pages rebuilds your website. Allow a few minutes for changes to appear.
What can I update?

Profile & contact: your introduction, photo, interests, social links, and résumé.
Projects: add, edit, hide, remove, or reorder project cards.
Notes: write posts, add images, and publish them.
Résumé: edit your experience, education, skills, and project descriptions.

Only accounts granted write access can save changes. Content saved to this public repository—including unpublished notes—is publicly readable. Don't add passwords or private information.
